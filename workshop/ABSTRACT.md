# Simulated Fly Brain, Persistent Trauma

The internet keeps tormenting simulated fly brains. We are giving one a memory so it can remember the bad times. We will test whether past experience helps the same brain avoid unfamiliar hazards, keep eating, and survive longer.

In this workshop, you'll learn how AI memory helps agents retain useful experience across sessions. Using search and retrieval, you'll build a memory system that helps agents recall past experiences and apply them to new challenges.

You will leave with a working system that learns from experience through retrieval, plus reusable code and tests for your own applications.
